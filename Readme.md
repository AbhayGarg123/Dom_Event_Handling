# Simple Interactive Greeter & Color Changer Webpage

A lightweight, beginner-friendly web application built with **HTML**, **CSS**, and **vanilla JavaScript**. This project demonstrates basic DOM manipulation, event handling, and dynamic text updating based on user input.

## 🚀 Features

* **Dynamic Greeting:** Updates the main header text from "Hello" to "Hello, [User Name]" in real-time as the user types their name.
* **Interactive UI:** Features color choice buttons and an input form layout aligned cleanly on the page.
* **Responsive Event Handling:** Uses JavaScript event listeners to capture input values efficiently.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for the layout.
* **CSS3:** Clean layout alignment and styling.
* **JavaScript (ES6):** DOM selection and real-time input event listeners.
